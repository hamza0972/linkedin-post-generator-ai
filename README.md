# 💼 LinkedIn Post Generator AI

An AI-powered web application that generates professional LinkedIn posts using Groq's LLaMA 3 model. Users can customize tone and audience to create engaging, high-quality content instantly.

---

## 🌐 Live Demo

👉 [Click](https://huggingface.co/spaces/hamza0972/linkedin-post-generator)

---

## 🚀 Features

- ✍️ Generate LinkedIn posts instantly using AI
- 🎭 Choose tone: Professional, Casual, Motivational, Storytelling
- 🎯 Define target audience for personalized content
- ⚡ Fast response using Groq LLaMA 3 model
- 🧠 Prompt-engineered high-quality outputs

---

## ⚙️ How It Works

1. User enters topic, tone, and audience
2. System builds a structured AI prompt
3. Groq LLaMA 3 processes the request
4. AI generates a professional LinkedIn post
5. Output is displayed in the UI

---

## 🛠 Tech Stack

- Python 🐍
- Gradio (UI Framework)
- Groq API (LLaMA 3)
- Prompt Engineering

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/hamza0972/linkedin-post-generator-ai.git
cd linkedin-post-generator-ai
````

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Locally

```bash
python app.py
```

---

## 🔐 Environment Variables

This project requires a Groq API key.

Set it as an environment variable:

```bash
GROQ_API_KEY=your_api_key_here
```

OR configure it in your deployment platform (Hugging Face, Render, etc.)
