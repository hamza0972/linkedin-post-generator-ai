
# 💼 LinkedIn Post Generator AI

An AI-powered tool that generates high-quality LinkedIn posts using Groq's LLaMA 3 model.

## 🚀 Features
- Generate LinkedIn posts instantly
- Choose tone (Professional, Casual, Motivational, Storytelling)
- Add target audience
- AI-powered content generation

## 🛠 Tech Stack
- Python
- Gradio
- Groq API (LLaMA 3)

## 📦 Installation
```bash
pip install -r requirements.txt
````

## ▶ Run

```bash
python app.py
```

## 🔐 API Key Required

Set environment variable:

```
GROQ_API_KEY=your_api_key
```
