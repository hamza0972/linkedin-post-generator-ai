# 📖 About

**LinkedIn Post Generator AI** is an AI-powered web application that helps users create engaging, professional LinkedIn posts in seconds.

Simply enter a **topic**, choose a **writing tone**, specify your **target audience**, and let **Groq's LLaMA 3.1 8B Instant** model generate a polished LinkedIn post complete with:

- ✨ Strong opening hook
- 📄 Short, readable paragraphs
- 😊 Relevant emojis
- 📌 Bullet points (when appropriate)
- ❓ A question to encourage engagement
- #️⃣ 4–6 relevant hashtags

The application is built with **Python**, **Gradio**, and the **Groq API**, providing a fast and user-friendly experience.

# ⚙️ How It Works

1. Enter your LinkedIn post topic.
2. Select your preferred writing tone.
3. Specify your target audience.
4. Click **Submit**.
5. The AI generates a complete LinkedIn post ready to publish.

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/hamza0972/linkedin-post-generator-ai.git
```

Navigate to the project directory:

```bash
cd linkedin-post-generator-ai
```

Create a virtual environment (optional but recommended):

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Locally

Start the application:

```bash
python app.py
```

The Gradio interface will open in your browser.

---

# 🔐 Environment Variables

This project requires a **Groq API Key**.

Create an environment variable named:

```text
GROQ_API_KEY
```

Example:

```bash
GROQ_API_KEY=your_api_key_here
```

### Hugging Face Spaces

If deploying on Hugging Face:

1. Open your Space.
2. Go to **Settings**.
3. Open **Repository Secrets**.
4. Add:

```text
GROQ_API_KEY=your_api_key_here
```
